# Memos v0.0.8 需求规格说明书

| 字段 | 值 |
|------|-----|
| 文档版本 | v0.0.8 |
| 状态 | Draft |
| 创建日期 | 2026-07-20 |
| 作者 | Tylor |
| 基线版本 | v0.0.7 |

## 1. 概述

v0.0.8 聚焦"产品化与体验补全"：让用户自行配置 AI Key 摆脱硬编码、将应用打包为 macOS 桌面软件实现一键启动、增强圈选续写能力支持多段拼接、修复材料节点无法记笔记的问题、以及支持常见办公文件的在线预览与编辑并赋予独特图标。

## 2. 功能需求

### A. AI API Key 设置

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-701 | 设置页新增 API Key 输入区 | P0 | Given 打开设置，When 查看，Then 可见"AI 配置"区域含 Key 输入框（密码遮罩）和保存按钮 |
| FR-702 | Key 持久化到 localStorage | P0 | Given 保存 Key，When 刷新页面，Then Key 仍保留且 API 调用使用新 Key |
| FR-703 | 未配置 Key 时友好提示 | P0 | Given 未设置 Key，When 发送 AI 请求，Then 提示"请先在设置中配置 API Key" |
| FR-704 | 仅支持阿里千问（Qwen） | P1 | Given 设置页，When 查看，Then 仅显示千问选项，无其他 provider |

### B. macOS 桌面应用打包

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-710 | 使用 Tauri 打包为 .app | P0 | Given 执行打包命令，When 完成，Then 生成可双击运行的 .app 文件 |
| FR-711 | 启动后内嵌 Web 服务 | P0 | Given 双击 .app，When 启动，Then 自动开启本地服务并打开窗口显示应用 |
| FR-712 | 窗口标题为 Memos | P1 | Given 应用运行，When 查看窗口，Then 标题栏显示"Memos" |
| FR-713 | 支持大版本打包脚本 | P1 | Given 执行 `npm run tauri:build`，When 完成，Then 输出 .dmg 安装包 |

### C. 圈选续写（多段拼接）

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-720 | 圈选浮层新增"续写"按钮 | P0 | Given 开启圈选并选中文字，When 浮层出现，Then 可见"续写 ⊕"按钮和原"加入笔记"按钮 |
| FR-721 | 续写将选中文字追加到当前笔记末尾 | P0 | Given 点击续写，When 执行，Then 选中文字以换行拼接到当前节点最后一条笔记 |
| FR-722 | 无笔记时续写自动创建新笔记 | P0 | Given 节点无笔记，When 点击续写，Then 创建新笔记并写入选中文字 |
| FR-723 | 多次续写累加 | P0 | Given 已续写一段，When 再次选中并续写，Then 新内容换行追加到同一条笔记末尾 |
| FR-724 | 续写后浮层关闭、选区清除 | P1 | Given 续写完成，When 观察，Then 浮层消失、文字选区清除 |

### D. 材料节点记笔记修复

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-730 | 材料节点全屏详情显示笔记区 | P0 | Given 打开材料节点详情，When 查看，Then 可见笔记区（新建/列表/编辑） |
| FR-731 | 材料节点侧栏详情显示笔记 | P0 | Given 点击材料节点，When 侧栏详情打开，Then 笔记区正常显示 |

### E. 办公文件预览与编辑

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-740 | PDF 在线预览 | P0 | Given 导入 PDF，When 双击节点，Then 全屏详情中渲染 PDF 内容 |
| FR-741 | Word(.docx) 在线预览 | P0 | Given 导入 docx，When 双击节点，Then 渲染文档内容（含格式） |
| FR-742 | Excel(.xlsx) 在线预览 | P1 | Given 导入 xlsx，When 双击节点，Then 渲染表格内容 |
| FR-743 | PPT(.pptx) 在线预览 | P1 | Given 导入 pptx，When 双击节点，Then 渲染幻灯片内容 |
| FR-744 | Markdown 在线编辑 | P0 | Given 导入 md，When 双击节点，Then 可编辑并实时预览 |
| FR-745 | 文件类型独特图标 | P0 | Given 画布节点，When 查看，Then PDF/Word/Excel/PPT/MD 各有对应品牌色图标 |
| FR-746 | 简单编辑能力 | P1 | Given 预览文件，When 点击编辑，Then 可修改文本内容并保存 |

## 3. 非功能需求

| ID | 需求 | 指标 |
|----|------|------|
| NFR-701 | 桌面应用启动时间 | < 3 秒 |
| NFR-702 | 文件预览加载 | < 2 秒（10MB 以内文件） |
| NFR-703 | API Key 安全 | 不明文出现在日志/网络请求 header 之外 |

## 4. MVP 范围

- P0：FR-701~703, FR-710~711, FR-720~723, FR-730~731, FR-740~741, FR-744~745
- P1：FR-704, FR-712~713, FR-724, FR-742~743, FR-746
