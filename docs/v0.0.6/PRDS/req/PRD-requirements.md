# Memos v0.0.6 需求规格

| 版本 | v0.0.6 | 日期 | 2026-07-20 |

## 概述
v0.0.6 聚焦交互细节打磨：推荐内容完整展示、模式切换重构（移入节点 AI 助手）、全屏详情视觉优化（居中+留缝模糊）、侧栏可拖拽、历史对话独立展示。

## 功能需求

### A. 推荐功能完善
| ID | 需求 | 优先级 |
|----|------|--------|
| FR-501 | 相关推荐卡片点击后展示完整内容（展开详情） | P0 |
| FR-502 | 推荐缓存真正生效：第二次打开同一节点立即显示缓存，不重新请求 | P0 |
| FR-503 | "换一批"按钮强制刷新推荐 | P0 |

### B. 手动分组可见性
| ID | 需求 | 优先级 |
|----|------|--------|
| FR-510 | 手动归纳入口可见：工具栏常驻"手动归纳"按钮（点击提示 Shift+点击选择节点） | P0 |
| FR-511 | 选中≥2节点时按钮高亮可用，显示选中数量 | P0 |

### C. 模式切换重构
| ID | 需求 | 优先级 |

| FR-522 | 模式切换影响 AI system prompt（学习/费曼/辩论/设计） | P0 |
