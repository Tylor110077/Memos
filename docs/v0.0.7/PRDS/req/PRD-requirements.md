# Memos v0.0.7 需求规格说明书

| 字段 | 值 |
|------|-----|
| 文档版本 | v0.0.7 |
| 状态 | Draft |
| 创建日期 | 2026-07-20 |
| 作者 | Tylor |
| 基线版本 | v0.0.6 |

## 1. 概述

v0.0.7 聚焦"知识沉淀"：让用户能把对话中的精华沉淀为节点笔记，用快捷键加速操作，并在节点内自由绘制白板表达关系。核心是让知识从"看过"变成"自己的"。

## 2. 功能需求

### A. 节点笔记（核心）

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-601 | 节点详情页可手动记笔记 | P0 | Given 打开节点全屏详情，When 在笔记区输入并保存，Then 笔记追加到原内容下方并持久化 |
| FR-602 | 笔记独立于原内容存储 | P0 | Given 节点有笔记，When 查看，Then 笔记与原内容分区显示，笔记带时间戳 |
| FR-603 | 对话内容整条加入笔记 | P0 | Given 对话中某条消息，When 点击"加入笔记"，Then 该条内容（含用户问题）追加到当前节点笔记 |
| FR-604 | 圈选对话文字加入笔记 | P0 | Given 开启"圈选"模式，When 选中对话中的部分文字并确认，Then 选中文字追加到笔记 |
| FR-605 | 用户问题可加入笔记 | P0 | Given 用户自己的消息，When 点击"加入笔记"，Then 用户问题也加入笔记（标注为"我的提问"） |
| FR-606 | 笔记在主页面详情显示 | P0 | Given 节点有笔记，When 在主页面点击节点打开详情面板，Then 详情面板显示笔记 |
| FR-607 | 笔记作为推荐参考 | P1 | Given 节点有笔记，When 生成相关推荐，Then 笔记内容作为推荐参考材料传给 AI |

### B. 快捷键系统

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-610 | 核心操作快捷键 | P0 | Given 默认配置，When 按下快捷键，Then 触发对应操作（如 Cmd/Ctrl+K 聚焦对话） |
| FR-611 | 快捷键设置中自定义 | P0 | Given 打开设置-快捷键，When 按下新组合键，Then 重新绑定并持久化 |
| FR-612 | 快捷键遵循行业惯例 | P0 | Given 默认快捷键，When 查看，Then 符合通用习惯（Cmd/Ctrl+K/N/F 等，输入框内不触发） |

### C. 详情页操作按钮

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-620 | 全屏详情显示分化按钮 | P0 | Given 打开节点全屏详情，When 查看操作区，Then 显示"分化"按钮且可用 |
| FR-621 | 全屏详情显示删除按钮 | P0 | Given 打开节点全屏详情，When 点击删除并确认，Then 节点被删除并关闭详情 |

### D. 节点白板（自由绘制）

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-630 | 节点可添加白板 | P1 | Given 打开节点详情，When 切换到白板，Then 显示可自由绘制的画板 |
| FR-631 | 白板支持图形与箭头 | P1 | Given 白板打开，When 绘制，Then 支持手绘、矩形、箭头、文字等（Excalidraw） |
| FR-632 | 白板内容持久化 | P1 | Given 白板有内容，When 保存后重新打开，Then 内容恢复 |

## 3. 非功能需求

| ID | 需求 | 指标 | 优先级 |
|----|------|------|--------|
| NFR-601 | 圈选响应 | 选中后确认弹窗 < 200ms 出现 | P0 |
| NFR-602 | 白板加载 | Excalidraw 懒加载，不阻塞首屏 | P1 |

## 4. MVP 范围

P0: FR-601~606, FR-610~612, FR-620~621
P1: FR-607, FR-630~632
