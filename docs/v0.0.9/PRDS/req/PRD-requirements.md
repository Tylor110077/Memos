# Memos v0.0.9 需求规格说明书

| 字段 | 值 |
|------|-----|
| 文档版本 | v0.0.9 |
| 状态 | Draft |
| 创建日期 | 2026-07-20 |
| 作者 | Tylor |
| 基线版本 | v0.0.8 |

## 1. 概述

v0.0.9 聚焦"认知可视化与交互打磨"：引入费曼模式认知评审同心圆让用户直观看到理解程度、修复 PDF 重复加载和对话丢失两个 bug、增强画中画小窗为可拖拽可调大小的全功能浮窗、新增 AI 侧栏整段对话加入笔记、以及全局动效过渡提升体验流畅度。

## 2. 功能需求

### A. 费曼模式认知评审同心圆

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-801 | 费曼对话记录构成同心圆可视化 | P0 | Given 节点使用费曼模式对话，When 查看认知面板，Then 显示同心圆：外环=节点知识范围，内环=理解程度填充 |
| FR-802 | AI 评价理解程度（5 档制） | P0 | Given 费曼对话结束或手动触发，When AI 评审，Then 返回 1-5 档位评分+理由 |
| FR-803 | 档位判定规则明确 | P0 | Given 评审结果，When 查看，Then 可见规则说明：1=未理解 2=模糊 3=基本 4=清晰 5=精通 |
| FR-804 | 设置中可开关自动认知评审 | P0 | Given 设置页，When 切换开关，Then 控制费曼对话结束后是否自动触发评审 |
| FR-805 | 同心圆在节点详情中展示 | P1 | Given 节点有评审记录，When 打开详情，Then 可见同心圆组件 |

### B. Bug 修复

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-810 | 新建笔记时 PDF 不重新加载 | P0 | Given PDF 节点已加载，When 新建笔记，Then iframe 不闪烁/不重载 |
| FR-811 | 详情→对话切换不新建对话 | P0 | Given 主对话有历史消息，When 打开详情再关闭，Then 主对话历史保留 |

### C. 画中画小窗增强

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-820 | 小窗内容可滚动查看 | P0 | Given 小窗显示，When 滚动小窗内容，Then 内容跟随滚动 |
| FR-821 | 视频小窗支持播放控制 | P1 | Given 节点含视频，When 小窗显示，Then 有播放/暂停按钮 |
| FR-822 | 小窗可拖拽调整位置 | P0 | Given 小窗显示，When 拖拽标题栏，Then 小窗跟随移动，无位置限制 |
| FR-823 | 小窗可拖拽调整大小 | P0 | Given 小窗显示，When 拖拽右下角手柄，Then 大小变化，限制 160px~400px |

### D. AI 侧栏整段对话加入笔记

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-830 | AI 侧栏新增"加入笔记"按钮 | P0 | Given AI 侧栏有对话，When 点击按钮，Then 整段对话（用户+AI）作为一条笔记加入当前节点 |
| FR-831 | 主对话面板同样支持 | P1 | Given 主对话有消息，When 点击按钮，Then 整段对话加入选中节点笔记 |

### E. 全局动效过渡

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-840 | 节点全屏详情打开/关闭动效 | P0 | Given 双击节点，When 详情打开/关闭，Then 有 scale+fade 过渡（200-300ms） |
| FR-841 | AI 侧栏展开/合上动效 | P0 | Given 点击 AI 按钮，When 侧栏展开/合上，Then 有 slide+fade 过渡 |
| FR-842 | Tab 切换过渡 | P1 | Given 切换内容/白板 Tab，When 切换，Then 有 fade 过渡 |
| FR-843 | 下拉菜单展开/收起动效 | P1 | Given 点击下拉，When 展开/收起，Then 有 scale-y+fade 过渡 |
| FR-844 | 主对话面板展开/收起动效 | P1 | Given 点击对话按钮，When 面板展开/收起，Then 有 slide 过渡 |

## 3. 非功能需求

| ID | 需求 | 指标 |
|----|------|------|
| NFR-801 | 动效帧率 | ≥ 55fps，无卡顿 |
| NFR-802 | 认知评审响应 | < 5 秒返回结果 |
| NFR-803 | 小窗拖拽流畅度 | 60fps 无延迟 |

## 4. MVP 范围

- P0：FR-801~804, FR-810~811, FR-820, FR-822~823, FR-830, FR-840~841
- P1：FR-805, FR-821, FR-831, FR-842~844
