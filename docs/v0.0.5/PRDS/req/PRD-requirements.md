# Memos v0.0.5 需求规格

| 版本 | v0.0.5 | 日期 | 2026-07-20 |

## 功能需求

### A. 数据隔离与缓存

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-401 | 画板数据隔离：切换画板后对话/推荐/节点完全独立 | P0 |
| FR-402 | 推荐结果缓存：首次触发后存储，不重复调用 API，手动"换一批"才刷新 | P0 |
| FR-403 | 对话历史按画板标注来源（如【心理学】标题前缀） | P0 |

### B. Sidebar 重构

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-410 | 移除顶部"推荐"Tab（保留详情内推荐） | P0 |
| FR-411 | 移除对话区顶部"生成节点"按钮（已有逐条生成） | P0 |
| FR-412 | 历史对话融入 sidebar（非全屏横屏） | P0 |
| FR-413 | Sidebar 可拖拽调整宽度（280px~600px） | P0 |
| FR-414 | 收起时无黑条，展开按钮与背景融合 | P0 |
| FR-415 | "开始对话"空状态改为 Memos 风格化设计（品牌字+点缀） | P1 |

### C. 主题归纳改造

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-420 | 自动归纳：工具栏按钮，AI 基于当前全部节点自动归纳主题 | P0 |
| FR-421 | 手动归纳：用户选中多个节点后触发归纳 | P0 |

### D. 全屏详情 + AI 侧栏

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-430 | 全屏详情页右侧可展开 AI 对话 sidebar | P0 |
| FR-431 | 该 sidebar 自动将当前节点加入上下文 | P0 |
| FR-432 | sidebar 可拖拽调整宽度 | P1 |
| FR-433 | 对话历史加入全局历史（带画板来源标注） | P0 |

### E. 连线交互增强

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-440 | 近距离连线时显示流动虚线预览 | P1 |
| FR-441 | 支持断开已有连线（选中边后 Delete 或右键断开） | P0 |

## MVP 范围
P0: FR-401~403, FR-410~414, FR-420~421, FR-430~431, FR-433, FR-441
P1: FR-415, FR-432, FR-440
