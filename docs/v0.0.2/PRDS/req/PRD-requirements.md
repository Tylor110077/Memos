## 1. 概述

v0.0.2 是 Studyboard 的体验升级版本，聚焦于：对话渲染质量、节点视觉与动效、内容深度展示、图谱可读性控制、以及交互细节打磨。目标是让产品从"能用"进化到"好用且有质感"。

## 2. 问题陈述

| 痛点 | 现状（v0.0.1） | v0.0.2 目标 |
|------|----------------|-------------|
| Markdown 渲染不全 | 表格显示异常，代码块/加粗支持不完整 | 完整 GFM 支持（表格/代码/加粗/列表等） |
| 节点视觉粗糙 | 简单色块矩形，无动效 | 参考 Obsidian Graph 风格，有呼吸感动效 |
| 生成节点粒度粗 | 只能对整段对话生成 | 支持对单条/多选回复生成节点 |
| 模式切换不明确 | 4 模式共用对话栏，无说明 | 每个模式有简介，切换有明确视觉反馈 |
| 材料导入无内容 | 仅存 URL，无抓取 | 自动抓取标题/图标/正文，内嵌原文+摘要 |
| 连线过多杂乱 | 全部显示，节点多时混乱 | 支持 N 度邻居过滤 / 极大连通子集 |
| 节点详情太简陋 | 小侧栏显示纯文本 | 全屏展开页：编辑器/内嵌浏览器+AI 摘要 |
| 推荐内容单一 | 仅知识性推荐 | 区分知识类 vs 趣闻类，随机出现趣闻 |
| 对话栏无动效 | 突然出现/消失 | 平滑滑入/滑出动画 |
| 对话栏展开位置不一致 | 收起后从固定位置展开 | 在哪里收起就从哪里展开 |

## 3. 设计原则

| 编号 | 原则 | 说明 |
|------|------|------|
| DP-1 | 质感优先 | 动效、排版、视觉细节体现产品品质 |
| DP-2 | 渐进展示 | 信息按需展开，不一次性堆砌 |
| DP-3 | 内容沉浸 | 打开节点即进入沉浸式阅读/编辑空间 |
| DP-4 | 可控复杂度 | 图谱视觉复杂度由用户自主调节 |

## 4. 功能需求

### 4.1 模块 A：Markdown 完整渲染

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-101 | 对话消息支持完整 GFM 渲染 | P0 | Given AI 回复含表格/代码块/加粗/列表，When 渲染时，Then 全部正确显示（表格有边框、代码有高亮） |
| FR-102 | 代码块语法高亮 | P0 | Given 消息含 ```python 代码块，When 渲染时，Then 显示带语法高亮的代码区域 |
| FR-103 | 表格完整渲染 | P0 | Given 消息含 Markdown 表格，When 渲染时，Then 表格有表头、边框、斑马纹 |

### 4.2 模块 B：节点视觉与动效（Obsidian 风格）

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-110 | 节点样式参考 Obsidian Graph | P0 | Given 画布渲染，When 查看节点，Then 节点为圆形/圆角气泡，有光晕效果，大小按层级/连接数变化 |
| FR-111 | 节点悬停动效 | P0 | Given 鼠标悬停节点，When hover，Then 节点轻微放大 + 光晕增强 + 相邻连线高亮 |
| FR-112 | 连线样式优化 | P1 | Given 画布渲染，When 查看连线，Then 连线为平滑曲线，有透明度，hover 时高亮 |
| FR-113 | 节点出现动画 | P1 | Given 新节点生成，When 添加到画布，Then 有从小到大 + 淡入的出现动画 |

### 4.3 模块 C：精细化节点生成

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-120 | 单条消息生成节点 | P0 | Given 对话中某条 AI 回复，When 用户点击该消息的"生成节点"按钮，Then 仅基于该条回复生成节点 |
| FR-121 | 多选消息生成节点 | P1 | Given 用户选中多条消息（checkbox），When 点击"生成选中节点"，Then 基于选中消息生成节点 |

### 4.4 模块 D：模式说明与切换反馈

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-130 | 模式简介展示 | P0 | Given 用户查看模式选择器，When hover 或首次使用，Then 每个模式显示一句话说明（学习="向AI提问学习新知"、费曼="向AI讲解你的理解"、辩论="为观点辩护"、设计="用知识做设计"） |
| FR-131 | 模式切换视觉反馈 | P0 | Given 用户切换模式，When 切换完成，Then 对话栏顶部显示当前模式名称+颜色标识，有切换过渡动画 |
| FR-132 | 模式切换分隔线 | P1 | Given 对话中途切换模式，When 新消息产生，Then 消息流中显示"已切换到XX模式"分隔提示 |

### 4.5 模块 E：材料内容抓取

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-140 | URL 导入自动抓取 | P0 | Given 用户导入 URL，When 确认导入，Then 自动抓取网页标题、favicon、正文内容 |
| FR-141 | 材料节点内嵌原文 | P0 | Given 材料节点已创建，When 打开节点详情，Then 可查看原文内容 + AI 生成的摘要 |
| FR-142 | 抓取失败降级 | P1 | Given URL 无法抓取（反爬/404），When 抓取失败，Then 降级为仅存 URL，提示用户 |

### 4.6 模块 F：图谱连线可见性控制

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-150 | 全部显示/隐藏连线切换 | P0 | Given 工具栏，When 切换连线模式，Then 可在"全部显示"和"聚焦模式"间切换 |
| FR-151 | N 度邻居过滤 | P0 | Given 选中某节点，When 设置显示度数（1/2/3/4），Then 仅显示该节点 N 度以内的邻居和连线，其余淡化 |
| FR-152 | 极大连通子集显示 | P2 | Given 选中某节点，When 选择"连通子集"模式，Then 仅显示该节点所在的极大连通子图 |

### 4.7 模块 G：节点全屏详情页

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-160 | 点击节点全屏展开 | P0 | Given 双击/点击展开按钮，When 节点展开，Then 占据 80%+ 屏幕空间，有展开动画 |
| FR-161 | 文本节点=编辑器 | P0 | Given 展开概念/理解节点，When 全屏查看，Then 显示类编辑器界面（Markdown 编辑+预览） |
| FR-162 | 材料节点=内嵌浏览器 | P0 | Given 展开材料节点（网页），When 全屏查看，Then 用 iframe 嵌入原文，可内部浏览 |
| FR-163 | 视频/PDF 内嵌播放 | P1 | Given 展开视频/PDF 材料节点，When 全屏查看，Then 内嵌播放器/阅读器 |
| FR-164 | AI 摘要区域 | P0 | Given 节点展开，When 查看底部，Then 显示 AI 生成的内容摘要 |
| FR-165 | 关闭回到画布 | P0 | Given 全屏详情打开，When 点击关闭/ESC，Then 有收缩动画回到画布 |

### 4.8 模块 H：知识 vs 趣闻区分

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-170 | 节点内容类型标记 | P1 | Given 节点创建，When 系统识别内容类型，Then 标记为"知识"或"趣闻"，视觉有区分 |
| FR-171 | 破茧推荐含趣闻 | P1 | Given 触发破茧推荐，When 返回结果，Then 混合知识类和趣闻类（如"19世纪胖子俱乐部"） |
| FR-172 | 趣闻节点视觉区分 | P1 | Given 趣闻类节点在画布上，When 查看，Then 有独特标识（如✨图标或特殊颜色） |

### 4.9 模块 I：对话栏动效与交互

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-180 | 对话栏滑入/滑出动画 | P0 | Given 打开/关闭对话栏，When 切换状态，Then 有 300ms 平滑滑动动画（非突然出现/消失） |
| FR-181 | 收起位置=展开位置 | P0 | Given 对话栏从右侧收起，When 再次展开，Then 从右侧滑出（位置一致） |

## 5. 非功能需求

| ID | 需求 | 指标 | 优先级 |
|----|------|------|--------|
| NFR-101 | 动效流畅度 | 所有动画 60fps，无掉帧 | P0 |
| NFR-102 | 全屏详情加载 | 展开动画 < 400ms | P0 |
| NFR-103 | 网页抓取超时 | < 10s，超时降级 | P1 |
| NFR-104 | 邻居过滤响应 | 切换度数后 < 200ms 完成渲染 | P0 |

FR-152

## 7. 约束与假设

- 网页抓取通过 Next.js API Route 服务端执行（避免 CORS）
- iframe 嵌入受目标网站 X-Frame-Options 限制，需降级处理
- Obsidian 风格为参考而非照搬，保持 Studyboard 自身设计语言
- 趣闻内容由 AI 生成，无需外部数据库
