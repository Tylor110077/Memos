# Memos v0.0.4 产品需求规格说明书

| 字段 | 值 |
|------|-----|
| 文档版本 | v0.0.4 |
| 状态 | Draft |
| 创建日期 | 2026-07-20 |
| 产品名 | Memos（原 Studyboard） |

---

## 1. 概述

v0.0.4 是产品更名+体验重塑版本。软件更名为 **Memos**，移除冗余功能（聚焦模式、双击创建），强化核心闭环（对话→节点），修复多项 UI 问题，并引入多主题切换系统。

## 2. 功能需求

### 模块 A：功能精简

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-301 | 移除聚焦模式 | P0 | Given 画布，When 查看工具栏，Then 无聚焦模式按钮和 FocusControl 组件 |
| FR-302 | 移除双击画布创建节点 | P0 | Given 双击画布空白区域，When 触发，Then 无任何反应（不创建节点） |
| FR-303 | 保留 Obsidian 拖拽物理效果 | P0 | Given 拖拽节点，When 移动时，Then 邻居被弹性拉动+碰撞效果仍在 |

### 模块 B：节点生成增强

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-310 | 每条 AI 回复下方有"生成节点"按钮 | P0 | Given AI 回复消息，When 查看，Then 底部有生成节点按钮 |
| FR-311 | 多选消息批量生成节点 | P0 | Given 多条 AI 回复，When 勾选多条后点击"生成选中节点"，Then 基于选中内容生成节点 |
| FR-312 | 独立"生成节点"入口（整合链接+文件） | P0 | Given 工具栏/对话栏，When 点击生成按钮，Then 弹出统一入口（URL/文件/对话内容三种来源） |

### 模块 C：推荐功能

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-320 | 基于当前节点推荐相关知识 | P0 | Given 选中节点，When 查看推荐区，Then 显示与当前节点相关的延伸知识推荐 |
| FR-321 | 推荐可一键开始学习 | P0 | Given 推荐列表，When 点击某项，Then 自动发送"给我讲讲{标题}"到对话 |

### 模块 D：画板与对话

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-330 | 画板选择器 hover 覆盖编辑/删除按钮 | P0 | Given hover 画板列表项，When 鼠标在行内任何位置，Then 编辑/删除按钮可见 |
| FR-331 | 切换画板自动居中 | P0 | Given 切换画板，When 新画板加载，Then 视图自动 fitView 居中 |
| FR-332 | 历史对话保存与查看 | P0 | Given 对话结束/刷新页面，When 重新打开，Then 可查看历史对话记录 |
| FR-333 | 对话栏滚动条美化 | P0 | Given 对话内容超出面板高度，When 滚动，Then 无白色滚动条（深色自定义滚动条） |

### 模块 E：品牌与主题

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-340 | 更名为 Memos | P0 | Given 页面加载，When 查看标题/Logo，Then 显示"Memos" |
| FR-341 | 多主题切换系统 | P1 | Given 设置面板，When 选择主题，Then 全局颜色/风格即时切换 |
| FR-342 | 至少 3 套主题 | P1 | 默认暗色 / 科技蓝紫 / 暖棕复古 |

## 3. 非功能需求

| ID | 指标 |
|----|------|
| NFR-301 | 主题切换 < 200ms 无闪烁 |
| NFR-302 | 历史对话加载 < 500ms |

## 4. MVP 范围

P0: FR-301~303, FR-310~312, FR-320~321, FR-330~333, FR-340
P1: FR-341~342
