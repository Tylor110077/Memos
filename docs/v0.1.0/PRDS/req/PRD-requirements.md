# Memos v0.1.0 需求规格说明书

| 字段 | 值 |
|------|-----|
| 文档版本 | v0.1.0 |
| 状态 | Draft |
| 创建日期 | 2026-07-20 |
| 作者 | Tylor |
| 基线版本 | v0.0.9 |

## 1. 概述

v0.1.0 聚焦"交互效率与视觉一致性"：为对话消息增加复制/编辑能力、让节点颜色可在设置中自定义、圈选新增 AI 解释功能、续写支持指定目标笔记、修复认知环 UI 溢出和按钮尺寸不一致问题、新增对话栏展开/关闭快捷键。

## 2. 功能需求

### A. 消息操作增强

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-901 | AI 消息复制按钮 | P0 | Given AI 回复显示，When 悬停，Then 可见复制按钮，点击后内容复制到剪贴板 |
| FR-902 | 用户消息重新编辑 | P0 | Given 用户消息显示，When 悬停，Then 可见编辑按钮，点击后可编辑并重新发送 |
| FR-903 | 主对话+节点侧栏均支持 | P0 | Given 任一对话界面，When 操作，Then 复制/编辑功能均可用 |

### B. 节点颜色可配置

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-910 | 设置页节点颜色配置区 | P0 | Given 打开设置，When 查看，Then 可见 5 种节点类型的颜色选择器 |
| FR-911 | 颜色图例展示 | P0 | Given 设置页，When 查看，Then 每种类型显示色块+名称+含义说明 |
| FR-912 | 颜色持久化 | P0 | Given 修改颜色，When 刷新页面，Then 画布节点颜色更新 |

### C. 圈选 AI 解释

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-920 | 圈选浮层新增"解释"按钮 | P0 | Given 圈选内容，When 查看浮层，Then 可见"💡 解释"按钮 |
| FR-921 | AI 简要解析格式 | P0 | Given 点击解释，When AI 返回，Then 以"单词拆分+核心含义+一句话总结"格式展示 |

### D. 续写指定笔记

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-930 | 续写时弹出笔记选择器 | P0 | Given 点击续写，When 有多条笔记，Then 弹出列表让用户选择目标笔记 |
| FR-931 | 仅一条笔记时直接续写 | P1 | Given 只有一条笔记，When 点击续写，Then 直接追加无需选择 |

### E. UI 修复

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-940 | 认知环不溢出 | P0 | Given 节点详情，When 查看认知环，Then 不超出容器边界 |
| FR-941 | 认知环圆心填满 | P0 | Given 认知环显示，When 查看，Then 内圆占满外环内部空间 |
| FR-942 | 按钮尺寸统一 | P0 | Given 主内容区和侧栏，When 对比，Then 操作按钮大小一致 |

### F. 对话栏快捷键

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-950 | 快捷键展开/关闭对话栏 | P0 | Given 按下快捷键，When 触发，Then 对话栏切换显隐 |
| FR-951 | 设置中可配置 | P0 | Given 设置页，When 查看快捷键，Then 可见"切换对话栏"绑定项 |
| FR-952 | 主页面+节点详情均可用 | P0 | Given 任一界面，When 按快捷键，Then 对应面板切换 |

## 3. MVP 范围

- P0：FR-901~903, FR-910~912, FR-920~921, FR-930, FR-940~942, FR-950~952
- P1：FR-931
