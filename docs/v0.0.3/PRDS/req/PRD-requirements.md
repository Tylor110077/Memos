## 1. 概述

v0.0.3 聚焦于物理交互质感、AI 上下文感知、多画板管理、以及材料导入重构。目标是让画布"活起来"（弹性物理），让 AI "知道你在看什么"（上下文注入），让知识组织更灵活（多画板），让材料导入更智能（自动路由）。

## 2. 问题陈述

| 痛点 | 现状 | v0.0.3 目标 |
|------|------|-------------|
| 拖拽无物理感 | 拖节点只移动自身，无弹性/碰撞 | 拖拽带动邻居，弹性连线，碰撞效果 |
| 手动连线不直观 | 需从 Handle 拖出 | 将两点拉近即可自动连线 |
| 连线有拐角 | SmoothStep 折线 | 纯直线连接 |
| 网页加载无反馈 | iframe 加载时空白 | 加载中显示 skeleton/spinner |
| 摘要非真实内容 | 仅存 URL | 实际抓取后 AI 生成摘要 |
| 全屏时无法问 AI | 全屏详情遮挡对话栏 | 右侧保留 AI 对话入口 |
| AI 不知上下文 | 选中节点后 AI 不知道你在说什么 | 选中节点自动注入对话上下文 |
| 只有一个画板 | 所有知识混在一张画布 | 多画板库，可新建/删除/切换 |
| 材料导入设计奇怪 | 手动选类型 | 自动路由：URL→抓取，文件→识别格式渲染 |

## 3. 功能需求

### 3.1 模块 A：物理交互增强

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-201 | 拖拽节点带动邻居 | P0 | Given 拖拽一个节点，When 移动时，Then 相邻节点被弹性拉动（距离越近力越大） |
| FR-202 | 弹性连线 | P0 | Given 节点被拖拽，When 连线拉伸，Then 连线像弹簧一样有弹性回弹效果 |
| FR-203 | 碰撞效果 | P1 | Given 两节点靠近，When 距离小于阈值，Then 产生排斥力避免重叠 |
| FR-204 | 纯直线连线 | P0 | Given 两节点有连接，When 渲染时，Then 连线为纯直线（无拐角/曲线） |
| FR-205 | 近距离自动连线 | P0 | Given 拖拽节点 A 靠近节点 B（距离 < 50px），When 松手，Then 自动创建 A-B 连线 |

### 3.2 模块 B：AI 上下文感知

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-210 | 选中节点注入上下文 | P0 | Given 用户选中/点击一个节点，When 在对话栏提问，Then AI 知道用户指的是哪个节点（自动将节点标题+内容加入 system prompt） |
| FR-211 | 全屏详情保留 AI 对话 | P0 | Given 节点全屏展开，When 查看右侧，Then 仍有 AI 对话面板可提问当前节点细节 |
| FR-212 | 上下文切换提示 | P1 | Given 用户切换选中节点，When 对话栏更新上下文，Then 显示"当前上下文：{节点标题}" 提示 |

### 3.3 模块 C：多画板管理

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-220 | 画板库概念 | P0 | Given 应用启动，When 查看，Then 有一个知识库包含多个画板 |
| FR-221 | 新建画板 | P0 | Given 画板库界面，When 点击新建，Then 创建空白画板并进入 |
| FR-222 | 切换画板 | P0 | Given 多个画板存在，When 选择另一个，Then 画布切换到对应画板的节点 |
| FR-223 | 删除画板 | P1 | Given 画板库界面，When 删除画板，Then 确认后删除该画板所有数据 |
| FR-224 | 重命名画板 | P1 | Given 画板库界面，When 编辑名称，Then 可修改画板标题 |

### 3.4 模块 D：材料导入重构

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-230 | 自动路由：URL vs 文件 | P0 | Given 用户输入/拖入内容，When 系统检测，Then 自动判断是 URL 还是文件并走对应流程 |
| FR-231 | URL 类型：抓取+摘要+原文 | P0 | Given 输入 URL，When 导入，Then 自动抓取内容→AI 生成摘要→节点含摘要+原文链接 |
| FR-232 | 文件类型：格式自动识别 | P0 | Given 拖入文件，When 系统检测，Then 自动识别 PDF/Word/Excel/MD 并正确渲染 |
| FR-233 | PDF 渲染 | P1 | Given 导入 PDF 文件，When 打开节点，Then 内嵌 PDF 阅读器 |
| FR-234 | Markdown 渲染 | P0 | Given 导入 .md 文件，When 打开节点，Then 渲染为格式化 Markdown |
| FR-235 | 网页加载状态 | P0 | Given 打开网页材料节点，When iframe 加载中，Then 显示 loading spinner |

### 3.5 模块 E：连线样式修正

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| FR-240 | 纯直线无拐角 | P0 | Given 任意两节点连线，When 渲染，Then 为 source→target 的纯直线（getStraightPath） |

### P0

### P1
FR-203, FR-212, FR-223~224, FR-233

## 6. 约束与假设

- 文件上传存储在浏览器本地（IndexedDB / OPFS）
- 多画板数据隔离，每个画板独立的 nodes/edges
- 物理模拟基于现有 d3-force，增强弹性参数
- 近距离连线使用距离检测，非 React Flow 原生连线
